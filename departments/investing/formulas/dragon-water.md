# 蛟龍取水（Dragon Drinking Water）— 發哥公式量化規則

**定義（原文精神）：** 主力沿 60 日均線盤升建倉完備後，洗盤至 60 日均線附近的圖形。

**來源：** 使用者指定「發哥價值圈」選股心法（8 張圖完整版）  
**性質：** Pattern-match screen；**非投資建議**  
**輸出風格參考：** `/workspace/dragon-water/summary.md`

---

## 均線與龍體

| 條件 | 規則（可程式化） |
|------|------------------|
| MA 集合 | 使用 **MA5、MA10、MA60**（日線） |
| 龍體／盤升 | 一段時間內股價多沿／站在 **MA60 之上**；**MA5、MA10 位於 MA60 之上**且整體向上為佳 |
| 先前漲幅 | 洗盤前常有約 **40–50%+** 的盤升段（掃描可用 prior_gain 門檻，例如 ≥25–30% 列入候選） |
| 蛟龍取水 | 回檔／震盪，**洗盤至 MA60 附近**（`dist_MA60` 接近 0；容許小幅跌破後再站回） |
| 取水時 MA60 距離感 | 心法敘述「60 日均線離得越遠越好」指洗盤過程相對高點／龍體的空間；實作上可對 **prior stretch above MA60** 加分 |

## 水坑（成交量）

| 指標 | 門檻 |
|------|------|
| 量能收縮比 `vol_contr` | 近端量／先前活躍量 |
| **Prefer（淺水坑）** | `vol_contr ≤ 0.40` |
| **Best（芝麻點）** | `vol_contr ≤ 0.25`（權重最高） |
| 意義 | 洗盤後沒人賣、市場安靜 → 水坑 |

## MACD

| 條件 | 規則 |
|------|------|
| **MACD 水上金叉** | DIF／DEA 在 **零軸上方** 發生金叉（或等價：MACD histogram 由負轉正且線在 0 上） |
| 用途 | 取水完成、動能轉折的輔助確認；命中則加分並在輸出標記「MACD水上金叉」 |

## 突破

| 條件 | 規則 |
|------|------|
| 前平台／前頭部 | 取水後接近或越过前一盤整區高點 |
| 標記 | `near/broke platform` |
| 操作心法對照 | 龍體明顯→持股待漲；取水＋水坑→逢低介入觀察；取水完成且突破前平台→堅決觀察買入區（**系統不下單**） |

## 市場別呈現

### 🇹🇼 台股 — 零股友善

- Prefer 低絕對股價，利於有限資金用**零股**買到有意義股數  
- **零股友善** ≈ `close ≤ NT$200`（**最佳 ≤ NT$100**）  
- 報告可分兩塊：① 零股友善清單 ② 依分數完整榜（含高價股）  
- 盡量附：收盤價、約 1 股／10 股成本  

### 🇺🇸 美股

- **列出全部**通過 A+B（或同等）篩選的命中，依 score 排序  
- 不因股價過濾（無零股邏輯）

## 評分要素（實作參考）

掃描實作可對下列加權（與既有 screener 精神一致）：

1. 沿／上 MA60 的 prior climb  
2. 回測 MA60 的 washout 品質  
3. **淺量水坑**（≤0.40／≤0.25 重權）  
4. prior stretch above MA60  
5. MACD 水上金叉 + 量能確認  
6. 近／破平台  
7. TW：零股友善 boost
